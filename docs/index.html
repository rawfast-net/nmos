Как добавить результат

Запустите nmos и согласитесь подготовить результат после проверки. Программа покажет данные и создаст ссылку на GitHub Issue. Проверьте текст и отправьте Issue вручную.

После проверки модератором результат появится на этой странице. Issue в публичном репозитории виден всем сразу после отправки.
