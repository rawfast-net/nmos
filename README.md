# NMOS

NMOS — программа для проверки VDS и VPS. Она показывает характеристики сервера, проверяет процессор, память, диск и сеть и помогает заметить возможные ограничения или несоответствия тарифу.

## Установка

Для Linux:

```bash
curl -fsSL https://github.com/rawfast-net/nmos/releases/latest/download/install-release.sh | bash
```

Если `curl` не установлен:

```bash
wget -qO- https://github.com/rawfast-net/nmos/releases/latest/download/install-release.sh | bash
```

После установки проверка запускается автоматически. Для повторной проверки выполните:

```bash
nmos
```

## Сравнение с тарифом

Укажите характеристики, обещанные провайдером:

```bash
nmos --claim-cores 4 --claim-ram-gb 8 --claim-disk-gb 80 --claim-cpu "EPYC 7763" --claim-net-mbps 1000
```

NMOS сравнит их с обнаруженными данными. Некоторые характеристики физического процессора могут быть скрыты виртуализацией, поэтому программа не всегда может подтвердить точную модель.

## Проверка скорости интернета

NMOS использует Ookla Speedtest. При обычном запуске программа проверяет его наличие и при необходимости предлагает установить. Установка выполняется только с вашего согласия.

Чтобы запустить проверку скорости отдельно от остальных сетевых измерений, можно использовать:

```bash
nmos --speedtest
```

Для выбора страны или конкретного сервера:

```bash
nmos --speedtest --region de
nmos --speedtest --country se --city Stockholm
nmos --speedtest --server-id 31120
```

Чтобы не проверять скорость:

```bash
nmos --no-speedtest
```

Если Ookla недоступен, программа сообщит об этом. Резервная проверка через iperf3 работает только при наличии настроенных тестовых серверов.

## Дополнительные возможности

Запуск без внешних сетевых запросов:

```bash
nmos --offline
```

Мониторинг состояния процессора в течение суток:

```bash
nmos --monitor --monitor-interval 900 --monitor-count 96 > monitor.jsonl
```

Проверка работы диска с базой данных:

```bash
nmos --db-bench --db-dir /var/tmp
```

Для дискового теста потребуется свободное место. Все доступные команды можно посмотреть через:

```bash
nmos --help
```

## Публикация результата

После проверки NMOS предложит поделиться результатом. Вы сможете посмотреть сведения перед отправкой или отказаться от публикации.

Если вы согласитесь, программа подготовит ссылку на GitHub. Результат нужно отправить на сайте самостоятельно. После проверки модератором он может появиться на публичной странице проекта.

**Важно:** созданная на GitHub заявка видна другим пользователям. Перед отправкой проверьте её содержимое.

## Как понимать результаты

Проверка показывает состояние сервера в момент запуска. Скорость и производительность могут меняться из-за нагрузки и других условий.

Если NMOS обнаружил подозрительные признаки, это ещё не означает, что провайдер намеренно обманывает. Для уверенного вывода могут понадобиться повторные проверки.
